## 发现并修复

- Framework StandardInput 默认可能在初始化前写入 UTF-8 BOM，使 Rust App Server 丢弃首条请求。最小 .NET 对比探测证实，将前导隔离成独立行后可立即初始化；生产管道后续显式使用 UTF-8 无 BOM。
- 新版 Codex 桌面进程名为 ChatGPT.exe，单凭 Codex.exe 会漏识别；现结合安装包路径兼容。
- Codex 宠物层也是 Chromium 窗口，仅按进程和窗口尺寸会误认；现排除透明工具窗口。
- 相对定位新增必须位于可识别编辑框上方的检查，不将任何屏幕空白都当作输入区安全位置。
